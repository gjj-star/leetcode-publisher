# 动态规划 + 前缀和：从“枚举间距”一步步推到 dp[n][k]

> Problem: [1621. 大小为 K 的不重叠线段的数目](https://leetcode.cn/problems/number-of-sets-of-k-non-overlapping-line-segments/description/)

# 思路

> 动态规划：$dp[n][k]$ 表示前 $n$ 个点里选 $k$ 条不重叠线段的方案数，转移里那串连续求和用前缀和 $pre$ 维护

这题是我第一道自己把状态转移啃出来的题。一开始想的是枚举，写着写着发现层数会随 $k$ 一直涨，根本写不完；换了个角度才摸到 DP 的门。

# 解题过程

## 第一步：暴力为什么写不出来

先拿 $k=2$ 试。两条线段 `(i, j)` 和 `(a, b)`，合法条件是 `i < j <= a < b`，允许共用端点，所以中间那格间距 `d = a - j >= 0` 也是合法的。

于是一个方案由四样东西决定：起点 `i`、左段长度、间距 `d`、右段长度。$k=3$ 就变成 3 个长度 + 2 个间距，$k$ 条就是 $k$ 个长度 + $k-1$ 个间距。

$k$** 不固定，这 **$2k-1$** 层循环就没法手写。**

## 第二步：真正决定未来的只有两个数

循环写不出来，就把它抽象成搜索：每一步挑一条新线段，要求 `left >= 上一条的右端点`（取等号就是共用端点，合法）、`right > left`。

但这么搜下去状态会炸。冷静想想，**前面具体挑了哪些线段其实不重要**——前面结束得越早，后面剩下的点越多；结束得越晚，后面越挤。真正决定未来的只有两个数：

> **还剩多少个点，还要挑几条线段。**

于是定义：

$dp[n][k]$：**前 **$n$** 个点里选 **$k$** 条不重叠线段的方案数**。

## 第三步：转移看最后一个点

只盯第 $n-1$ 号点（前 $n$ 个点里的最后一个），分两种情况：

- **不作为任何线段的右端点** → $k$ 条线段全落在前 $n-1$ 个点里，方案数 $dp[n-1][k]$；
- **作为右端点** → 最后一条线段是 $[t,\ n-1]$，剩下的 $k-1$ 条只能挤在 $0 \sim t$ 里，方案数 $dp[t+1][k-1]$。$t$ 从 $0$ 取到 $n-2$，全加起来。

$$
dp[n][k] = dp[n-1][k] + \sum_{i=1}^{n-1} dp[i][k-1]
$$

## 第四步：那串求和交给前缀和

上面那个 $\sum$ 每次都要重新累一遍，$n$ 一大就白算了。开一个 $pre$ 专门存这一列的累计：

$$
pre[n][k] = dp[1][k] + dp[2][k] + \cdots + dp[n][k]
$$

转移立刻变干净：

$$
dp[n][k] = dp[n-1][k] + pre[n-1][k-1]
$$

初始化有个坑：$k=0$ 时是 **1 不是 0**——“一条都不选”本身就是一种方案。所以 $dp[n][0]=1$，而点数不够时 $dp[0][k]=0\ (k>0)$。这个我想当然写错过。

## 第五步：滚动数组降维

算第 $n$ 行只用到第 $n-1$ 行，再往前的行再也不碰，所以两行就够了，空间从 $O(nk)$ 压到 $O(k)$。

代价是 $k$ 必须**倒序**遍历——正序的话，这一轮刚更新过的 $pre[k-1]$ 会被当成上一轮的值用掉。

# 复杂度

- 时间复杂度: $O(nk)$
- 空间复杂度: $O(k)$（滚动数组；不压的话是 $O(nk)$）
- 代码复杂度：10 行

# Code

```python3
class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7

        dp = [0] * (k + 1)     # dp[j]：上一轮里选 j 条线段的方案数
        pre = [0] * (k + 1)    # pre[j]：dp[j] 这一列的前缀和

        dp[0] = 1              # 一条都不选，也算一种方案

        for _ in range(n):
            # 倒序：保证用到的 pre[j-1] 还是上一轮的值
            for j in range(k, 0, -1):
                dp[j] = (dp[j] + pre[j - 1]) % MOD
                pre[j] = (pre[j] + dp[j]) % MOD

            pre[0] = (pre[0] + dp[0]) % MOD

        return dp[k]
```

# 总结

$k$** 不固定 → 循环写不出来 → 抽象成“不断挑下一条线段” → 发现真正决定未来的只有“剩余点数 + 剩余线段数” → 落成 **$dp[n][k]$**。** 转移里冒出一串求和，用 $pre$ 前缀和接住；又发现只依赖上一行，再用滚动数组把空间压到 $O(k)$。

这题卡我最久的不是转移，是 $dp[n][0]=1$ 那个初始化——“不选”也是一种选法。
